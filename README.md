
# 📜 Gemini Chat App  
🔥 AI-powered chatbot using **Google's Gemini API**, built with **Jetpack Compose** and **Firebase Authentication**.  



📺 **[Demo Video](https://github.com/user-attachments/assets/fcbd2fc4-0033-45d2-b405-80e731456f01)**  
**Recorded On Emulator, will be smoother and faster on Your Physical Device**
---

## 🚀 Features  
✅ **Chat with AI** – Send text and images to Gemini AI.  
✅ **Image Input** – Supports uploading and analyzing images.  
✅ **Firebase Authentication** – Secure Google sign-in.  
✅ **Dark Mode UI** – Modern and clean black-themed interface.  
✅ **Chat History** – View past conversations anytime.  
✅ **Personalized Experience** – Uses Google account name and profile photo.
✅ **Parsed AI Responses** – Well-structured and formatted responses.
✅ **Animated Typing Effect** – AI replies appear as if being typed in real time.
✅ **Jetpack Compose** – Fully built with Compose for smooth UI/UX.  

---

## 🎯 How It Works  
1️⃣ **Sign in** using Google Authentication.  
2️⃣ **Enter your prompt** in the chat field.  
3️⃣ **Upload an image** for AI to analyze.  
4️⃣ **Receive a response** from Gemini AI instantly.  
5️⃣ **View past conversations** anytime with **Chat History**.  
6️⃣ **Personalized UI** – Your **Google name & profile picture** are displayed.

## 🏗 Installation Guide  

### 1️⃣ Clone the repository  
```sh
git clone https://github.com/Shahbazsam/GeminiChatApp.git
cd GeminiChatApp
```

### 2️⃣ Set up API Keys  
- Get your **Gemini API Key** from **[Google AI Studio](https://aistudio.google.com/)**.  
- Open your project’s `gradle.properties` file and add:  
  ```properties
  GEMINI_API_KEY="your_api_key_here"
  ```
- The app will securely load the API key from **gradle.properties**.  

### 3️⃣ Run the app  
```sh
./gradlew assembleDebug
```
